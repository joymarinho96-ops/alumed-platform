COMO USAR AGORA:
════════════════════════════════════════════════════════════

1. INICIAR SERVIDOR:
   $ cd "c:\Users\joyce\OneDrive\Desktop\HHISTOLOGY"
   $ python -m http.server 8000

2. ABRIR NO NAVEGADOR:
   http://localhost:8000/microscopio_virtual.html

3. USAR AS FERRAMENTAS:
   P = Desenhar (Pencil)
   E = Borracha (Eraser)
   L = Lock Zoom (não mover imagem)
   C = Limpar desenhos
   D = Download
   +/- = Zoom


ATALHOS DISPONÍVEIS:
════════════════════════════════════════════════════════════
P       → Ativar/desativar pencil (desenho)
E       → Ativar/desativar eraser
L       → Lock/unlock zoom
C       → Limpar desenhos
D       → Download da imagem
+       → Zoom in
-       → Zoom out
